# Algerian Forest Fire Prediction 🔥🌲

An end-to-end Machine Learning project that predicts the occurrence of forest fires using environmental and weather-related features from the Algerian Forest Fires dataset.

The project covers the complete machine learning workflow, including data preprocessing, exploratory data analysis, feature engineering, model training, evaluation, model saving, and deployment using a Flask API.

### Tech Stack

* Python
* Pandas & NumPy
* Scikit-learn
* Flask
* Machine Learning
* Git & GitHub
